Asset manager reference model · SM-01 Distribution Performance

Four needs, one certified base

"Net flows, last quarter" comes back four ways, and every one of them is a legitimate need: gross for the field, settlement date for the ledger, reinvestments for the fund, approved post-close adjustments for the board. This page shows how each becomes a named measure defined once on one certified base, where that definition is captured in the taxonomy and the data products, how the semantic model publishes it, and which input rows it acts on. The rail under the diagram places every column in a Databricks Unity Catalog catalog, so the same picture reads as the deployment.

Trace one of the four needs

Each team's number is the certified base with one lever set differently. Pick a team to light where that lever is set once, where it is applied, and which named measure carries it. The definition cards below the diagram give the detail.

How the selected number is built, left to right

Pick a team above. The chain on the left produces one certified figure; the dashed step after it is the one certified line that turns it into the measure this audience needs, named by the lever that defines it.

The one rule. A data product assembles what the Data Domains master; it never remasters them. A certified number is defined in one product only, and every other product, scorecard, payout and assistant reads it from there. That is why the diagram has one box where the rule is applied and many boxes that only read.

The certified base

Net Flows

Measure Definition · certified
Taxonomy

Says what the number is, once, with an owner.

Definition
Gross sales less redemptions, including net exchanges, excluding reinvestments.
Formula
Gross Sales + Exchanges In − Redemptions − Exchanges Out
Counts
Purchases, exchanges in, new-owner transfers in, SMA contributions, ETF creations
Leaves out
Reinvestments, share-class conversions, same-owner transfers
Date basis
Trade date
Owner
Head of Distribution Analytics

Measure Definition TX-MEA-004 to 012, measure TX-MEA-034; aligned with ICI net new cash flow and EFAMA net sales.

Data product

Stores the definition and computes the figure.

Definition in
DP-008's measure definition table, one row per version, with the Flow Treatment Rule choices as columns
Values in
DP-008's measure value table, column net_flows
One row =
one measure × one period × one dimension cut × one snapshot
Locked
Final snapshot on business day 8; changed only by a restatement

dp_008.measure_definition · dp_008.measure_value

Semantic model

Publishes the figure; defines nothing.

Metric
Net Flows in SM-01 Distribution Performance = the sum of DP-008's column
Guard rails
One dimension cut per query, monthly periods, the current locked snapshot
Default
Trailing 12 locked months

sum(flows_aum.net_flows), source DP-008 / Net Flows

Input

Starts from every attributed trade.

Rows

Check

Snapshot

Restatement
Reason, periods affected, amount, approver, compensation impact
Reasons today

To confirm
